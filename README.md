# MyNewron Frontend

Welcome to **MyNewron** 👋
This is an Expo project created with `create-expo-app` for managing your notes and documents.

---

## Features

- **Create notes**: Add plain text, audio recordings, or upload files.
- **Sync with server**: When convenient, sync your notes with the backend — perfect for working remotely.
- **Clustered view**: Visualize your documents grouped in the **MyNewron** section.
- **Backend connection via QR**: Connect easily to your server by scanning a QR code.

---

## Get started

### Install dependencies

```bash
npm install
```

### Start the app

```bash
npx expo start
```

In the output, you'll find options to open the app in:

- **Development build**
- **Android emulator**
- **iOS simulator**
- **Expo Go**, a limited sandbox for trying out app development with Expo
